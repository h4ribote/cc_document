<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">CLI から MCP サーバーを認証</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede">新しい `claude mcp login <name>` および `claude mcp logout <name>` コマンドは、インタラクティブな <code>/mcp</code> メニューの代わりに、シェルから設定済みの MCP サーバーを認証します。`claude mcp login` はサーバーの OAuth フローを直接実行し、`claude mcp logout` は保存された認証情報をクリアします。</p>

  <p className="digest-feature-try">セッションを開かずに設定済みサーバーの OAuth フローを実行します：</p>

  ```bash terminal theme={null}
  claude mcp login sentry
  ```

  <a className="digest-feature-link" href="/docs/ja/docs/mcp#authenticate-from-the-command-line">コマンドラインから認証</a>
</div>

<div className="digest-feature">
  <div className="digest-feature-header">
    <span className="digest-feature-title">シェルモードがコマンド出力に応答</span>
    <span className="digest-feature-pill">v2.1.186</span>
  </div>

  <p className="digest-feature-lede"><code>!</code> プレフィックスで実行するコマンドは、出力がトランスクリプトに記録されると Claude からの応答を取得するようになったため、<code>! npm test</code> を実行して、2 番目のプロンプトなしで失敗の説明を取得できます。応答のコストは通常のプロンプトを送信するのと同じです。出力がコンテキストに追加されるが応答がない以前の動作を保つには、<code>settings.json</code> で <code>respondToBashCommands</code> を <code>false</code> に設定します。</p>

  <p className="digest-feature-try">コマンドを実行して、その出力に応答を取得します：</p>

  ```text Claude Code theme={null}
  > ! npm test
  ```

  <a className="digest-feature-link" href="/docs/ja/docs/interactive-mode#shell-mode-with-prefix">! プレフィックス付きシェルモード</a>
</div>

<div className="digest-wins">
  <p className="digest-wins-title">その他の改善</p>

  <div className="digest-wins-grid">
    <div><code>/rewind</code> は <code>/clear</code> が実行される前の会話を再開できるようになりました</div>
    <div>新しい <code>sandbox.credentials</code> 設定は、サンドボックス化されたコマンドが認証情報ファイルとシークレット環境変数を読み取ることをブロックします</div>
    <div>組織で設定されたモデル制限がモデルピッカー、`--model`、<code>/model</code>、および <code>ANTHROPIC\_MODEL</code> に適用されるようになり、制限されたモデルが選択されると「組織の設定により制限されています」というメッセージが表示されます</div>
    <div>新しい <code>autoMode.classifyAllShell</code> 設定はすべての Bash および PowerShell コマンドをオートモード分類器にルーティングし、拒否理由がトランスクリプト、拒否トースト、および <code>/permissions</code> に表示されるようになりました</div>
    <div>新しい <code>claude\_code.assistant\_response</code> OpenTelemetry ログイベントはモデルの応答テキストを含み、既にプロンプトコンテンツをログしているデプロイメントはアップグレード時に受け取り始めるため、プロンプトのみを保つには <code>OTEL\_LOG\_ASSISTANT\_RESPONSES=0</code> を設定します</div>
    <div>バックグラウンドサブエージェントは、自動拒否の代わりにメインセッションで権限プロンプトを表示するようになりました。ダイアログはどのエージェントが要求しているかを表示し、Esc はそのツールのみを拒否します</div>
    <div><code>/install-github-app</code> は GitHub App のみをインストールして、Actions ワークフローとシークレットステップをスキップできるようになりました</div>
    <div>サンドボックスネットワーク権限ダイアログで許可するホストは、セッションの残りの間記憶され、接続するたびに再度プロンプトが表示されなくなります</div>
    <div>ストリーミング応答は約 37% 少ない CPU を使用し、ターミナル出力キャッシュからの長いセッションメモリ増加が削減されました</div>
    <div>`/review <pr>` は <code>/code-review medium</code> と同じレビューエンジンを使用するようになりました</div>
    <div>Bash モード <code>!</code> コマンドはライブファイルパスオートコンプリートを取得します</div>
  </div>
</div>
