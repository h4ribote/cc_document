    <span className="digest-feature-pill">v2.1.178</span>

  <p className="digest-feature-lede">Deny および ask permission ルールは、<code>Tool(param:value)</code> 構文を使用してツールの入力パラメータをマッチングできるようになりました。例えば、<code>Agent(model:opus)</code> は Opus モデルティアをリクエストするサブエージェントの生成にマッチします。値はワイルドカード `*` を受け入れるため、<code>Agent(isolation:\*)</code> は任意の明示的な isolation 値にマッチします。</p>

  <p className="digest-feature-try"><code>settings.json</code> の deny リストにパラメータルールを追加します：</p>

  ```json .claude/settings.json {3} theme={null}
  {
    "permissions": {
      "deny": ["Agent(model:opus)"]
    }
  }
  ```

  <a className="digest-feature-link" href="/docs/ja/permissions#match-by-input-parameter">Match by input parameter</a>
</div>

  <p className="digest-feature-lede"><code>key=value</code> を <code>/config</code> に渡して、Settings インターフェースを開かずに設定を直接変更します。この構文は、<code>-p</code> フラグを使用した非対話モードおよび Remote Control からも機能します。</p>

  <p className="digest-feature-try">プロンプトから <code>thinking</code> 設定を設定します：</p>

  ```text Claude Code theme={null}
  > /config thinking=false
  ```

<div className="digest-wins">
  <p className="digest-wins-title">その他の改善</p>

  <div className="digest-wins-grid">
    <div>Auto mode は、ローカルワークを破棄するよう要求しなかった場合に破壊的な git コマンド（`git reset --hard`、`git clean -fd`、`git stash drop`）をブロックし、特定のスタックの破棄を要求しない限り <code>terraform destroy</code> をブロックします</div>
    <div>新しい <code>attribution.sessionUrl</code> 設定を <code>false</code> に設定して、web および Remote Control セッションのコミットと PR から claude.ai セッションリンクを省略します</div>
    <div><code>/config</code> インターフェースでは、Enter と Space の両方が選択された設定を変更し、Esc は元に戻す代わりに保存して閉じるようになりました</div>
    <div>新しい <code>sandbox.allowAppleEvents</code> オプトイン設定により、サンドボックス化されたコマンドは macOS で Apple Events を送信できます</div>
    <div><code>CLAUDE\_CLIENT\_PRESENCE\_FILE</code> をマーカーファイルに指定して、マシンにいる間はモバイルプッシュ通知を抑制します</div>
    <div>長い段落は、最初の改行を待つ代わりに、行ごとにストリーミングされるようになりました</div>
    <div>API 接続が思考中に切断された場合、「Connection closed while thinking」を表示する代わりに自動的に再試行されます</div>
    <div><code>CLAUDE\_CODE\_EXPERIMENTAL\_AGENT\_TEAMS=1</code> が設定されている場合、すべてのセッションに 1 つの暗黙的なチームがあるため、Agent ツールの <code>name</code> パラメータを使用してチームメイトを直接生成できます</div>
    <div>ネストされた <code>.claude/skills</code> ディレクトリ内のスキルは、そこでファイルを操作するときに読み込まれます。名前の競合がある場合、ネストされたスキルは `<dir>:<name>` として表示されるため、両方が利用可能なままです</div>
    <div>カスタム <code>ANTHROPIC\_BASE\_URL</code> および Foundry でプロンプトキャッシングが読み取られない問題を修正しました</div>
    <div>ネットワークドライブおよびクラウド同期フォルダで Write および Edit が 0 バイトまたは切り詰められたファイルを生成する問題を修正しました</div>
  </div>
</div>
